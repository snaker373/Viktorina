```cpp
struct Питання {
    string текст;              // Текст питання
    vector<string> варіанти;   // Варіанти відповідей
```

## Функції

### Робота з консоллю

#### встановитиКолір()

Встановлює колір тексту та фону консолі.

```cpp
void встановитиКолір(Color колірТексту, Color колірФону = ЧОРНИЙ);
```

**Параметри:**
- `колірТексту` — колір тексту (enum Color)
- `колірФону` — колір фону (за замовчуванням ЧОРНИЙ)

**Приклад:**
```cpp
встановитиКолір(ЯРКИЙ_ЗЕЛЕНИЙ, ЧОРНИЙ);
cout << "Зелений текст";
скинутиКолір();
```

---

#### скинутиКолір()

Скидає колір до стандартного (білий текст на чорному фоні).

```cpp
void скинутиКолір();
```

```cpp
скинутиКолір();
```

### Відображення

#### показатиЗаголовок()

**Приклад:**

#### показатиПрогресБар()

Відображає прогрес-бар проходження вікторини.

```cpp
void показатиПрогресБар(int поточний, int всього);
```

**Параметри:**
- `поточний` — поточний номер питання
- `всього` — загальна кількість питань

**Приклад:**
```cpp
показатиПрогресБар(5, 10);
```

---

#### показатиПитання()

Відображає питання та варіанти відповідей.

```cpp
void показатиПитання(const Питання& п, int номерПитання, int всьогоПитань);
```

**Параметри:**
- `п` — посилання на структуру Питання
- `номерПитання` — номер поточного питання
- `всьогоПитань` — загальна кількість питань

**Приклад:**
```cpp
показатиПитання(питання[0], 1, 10);
```

---

#### показатиПравильнаВідповідь()

## Точка входу

### main()

Головна функція програми.

```cpp
int main();
```

**Повертає:** `int` — код завершення (0 при успіху)

**Приклад:**
```cpp
int main() {
    встановитиКодування();
    встановитиЗаголовокВікна();
    // ... код програми
    return 0;
}
```

---

## Приклад використання

```cpp
#include <iostream>
#include "вікторина.cpp"

using namespace std;

int main() {
    // Налаштування
    встановитиКодування();
    встановитиЗаголовокВікна();

    // Завантаження питань
    vector<Питання> питання = завантажитиПитання();

    // Відображення заголовка
    очиститиЕкран();
    показатиЗаголовок();

    // Відображення питання
    показатиПитання(питання[0], 1, питання.size());

    // Очікування відповіді
    int відповідь;
    cin >> відповідь;

    // Перевірка
    if (відповідь - 1 == питання[0].правильнаВідповідь) {
        встановитиКолір(ЯРКИЙ_ЗЕЛЕНИЙ);
        cout << "Правильно!";
        скинутиКолір();
    }

    return 0;
}
```
