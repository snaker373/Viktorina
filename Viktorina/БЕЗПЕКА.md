## Загальні принципи

### Принцип найменшої привілеї

Програма працює з мінімальними правами:
- Не потребує адміністраторських прав
- Не змінює системні налаштування
- Не звертається до мережі

### Принцип відкритості

- Вихідний код відкритий
- Можна перевірити код
- Прозора логіка

## Реалізовані заходи

### Валідація введення

```cpp
// Перевірка діапазону
if (відповідьКористувача >= 1 && відповідьКористувача <= 4) {
    // обробка
}
```

### Обробка помилок

```cpp
// Перевірка компіляції
if (%errorlevel% neq 0) {
    echo Помилка компіляції!
    pause
    exit /b 1
}
```

### Безпечне використання пам'яті

- Використання `std::vector` замість C-масивів
- Перевірка розмірів перед доступом
- Використання `std::string` замість `char*`

## Відомі вразливості

### Вразливість 1: Переповнення буфера

**Статус:** ✅ Виправлено

**Рішення:** Використання `std::vector` та `std::string`

---

### Вразливість 2: Введення поза діапазоном

**Статус:** ✅ Виправлено

**Рішення:** Валідація введення користувача

---

### Вразливість 3: Неконтрольований ввід

**Статус:** ✅ Виправлено

**Рішення:** Перевірка типу та діапазону

## Рекомендації для користувачів

### Безпечне використання

1. ✅ Завантажуйте з надійних джерел
2. ✅ Перевіряйте контрольні суми
3. ✅ Не модифікуйте виконуваний файл
4. ✅ Використовуйте актуальну версію

Програма НЕ збирає:

### Збереження даних

Програма НЕ зберігає:

- ❌ Введені дані
- ❌ Налаштування
