## Встановлення компілятора

### Варіант 1: MinGW (рекомендовано)

1. Завантажте MinGW-w64 з [mingw-w64.org](https://www.mingw-w64.org/)
2. Запустіть інсталятор
3. Виберіть "x86_64" для 64-бітної системи
4. Виберіть "posix" та "seh"
5. Вкажіть папку для встановлення (наприклад, `C:\mingw64`)
6. Додайте шлях до бінарних файлів у PATH:
   - Відкрийте "Система" → "Додаткові параметри системи"
   - Натисніть "Змінні середовища"
   - Знайдіть "Path" і натисніть "Змінити"
   - Додайте `C:\mingw64\bin`

### Варіант 2: Visual Studio

1. Завантажте Visual Studio Community з [visualstudio.microsoft.com](https://visualstudio.microsoft.com/)
2. Запустіть інсталятор
3. Виберіть "Розробка на C++ для настільних систем"
4. Натисніть "Встановити"

### Варіант 3: TDM-GCC

1. Завантажте з [jmeubank.github.io/tdm-gcc](https://jmeubank.github.io/tdm-gcc/)
2. Запустіть інсталятор
3. Виберіть "Create" для створення нового встановлення
4. Виберіть "MinGW-w64/TDM (64-bit)"
5. Додайте шлях до PATH

## Компіляція

### Через bat-файл (найпростіше)

Просто двічі клікніть на `запуск.bat`

### Через командний рядок

```bash
cd "шлях\до\папки\Вікторина"
g++ -std=c++11 вікторина.cpp -o вікторина.exe
```

### Через make

```bash
cd "шлях\до\папки\Вікторина"
make -f Makefile.ua
```

### Через Visual Studio

1. Відкрийте Visual Studio
2. Створіть новий проект "Console App"
3. Скопіюйте вміст `вікторина.cpp` у ваш файл
4. Натисніть F5 для запуску

## Вирішення проблем

### Помилка "g++ не знайдено"

**Рішення:** Перевірте, що g++ встановлено і додано в PATH.

### Помилка компіляції

**Рішення:**
1. Перевірте, що файл `вікторина.cpp` існує
2. Переконайтеся, що компілятор підтримує C++11
3. Спробуйте інший компілятор

### Не відображаються українські літери

**Рішення:**
1. Переконайтеся, що файл збережено в UTF-8
2. Перевірте налаштування консолі
3. Спробуйте інший шрифт (Consolas, Lucida Console)

### Програма закривається одразу

**Рішення:** Запустіть через `запуск.bat` або `запуск_вікно.bat`
