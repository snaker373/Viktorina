# 📋 ІНСТРУКЦІЯ

## Як запустити вікторину

### Найпростіший спосіб:

1. Двічі клікніть на файл `запуск.bat`
2. Програма автоматично скомпілюється і запуститься

### Для запуску в окремому вікні:

1. Двічі клікніть на файл `запуск_вікно.bat`
2. Вікторина відкриється в новому вікні консолі

## Як скомпілювати вручну

Відкрийте командний рядок у папці проекту і виконайте:

```bash
g++ -std=c++11 вікторина.cpp -o вікторина.exe
```

Потім запустіть:

```bash
вікторина.exe
```

## Як грати

1. Виберіть "Почати вікторину" в головному меню
2. Введіть номер правильної відповіді (1-4)
3. Натисніть Enter для переходу до наступного питання
4. Після завершення подивіться свій результат
5. Можете спробувати ще раз!

## Структура проекту

```
Вікторина/
├── вікторина.cpp       — основний код програми
├── запуск.bat          — скрипт для запуску
├── запуск_вікно.bat    — запуск в окремому вікні
├── Makefile.ua         — файл для make
├── README.ua.md        — документація
└── ІНСТРУКЦІЯ.md       — цей файл
```

## Вимоги до системи

- Windows 7 або новіша
- Компілятор g++ або Visual Studio
- Підтримка UTF-8

## У разі проблем

Якщо програма не запускається:

1. Переконайтеся, що встановлено компілятор g++
2. Перевірте, що файл `вікторина.cpp` знаходиться в тій же папці
3. Спробуйте запустити через командний рядок

## Контакти

Якщо виникли питання або знайшли помилку — повідомте розробнику.
