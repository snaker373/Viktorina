## Способи внеску

### 📝 Додавання питань

Додайте нові цікаві питання до вікторини!

**Як це зробити:**
1. Відкрийте файл `вікторина.cpp`
2. Знайдіть функцію `завантажитиПитання()`
3. Додайте нове питання:

```cpp
{
    "Ваше питання?",
    {"Варіант 1", "Варіант 2", "Варіант 3", "Варіант 4"},
    0 // індекс правильної відповіді (0-3)
},
```

## Процес внеску

### Крок 1: Fork

1. Зробіть fork репозиторію
2. Клонуйте свій fork

### Крок 2: Гілка

1. Створіть нову гілку
2. Назвіть її описово (наприклад, `feature/нові-питання`)

### Крок 3: Зміни

1. Внесіть свої зміни
2. Тестуйте їх
3. Комітуйте з описовим повідомленням

### Крок 4: Pull Request

1. Надішліть pull request
2. Опишіть свої зміни
3. Чекайте на відгук

## Коміт-повідомлення

### Формат:

```
[Тип] Короткий опис

Детальний опис (за потреби)
```

### Типи:

- `feat` — нова функція
- `fix` — виправлення помилки
- `docs` — зміни в документації
- `style` — зміни стилю
- `refactor` — рефакторинг
- `test` — тести
- `chore` — інші зміни

### Приклади:

```
feat: додати 5 нових питань про історію

Додано питання про:
- Давню Грецію
- Римську імперію
- Середньовіччя
- Ренесанс
- Просвітництво
```

```
fix: виправити помилку з кодуванням

Проблема: українські літери не відображалися
Рішення: додано встановлення UTF-8
```
