# 🎯 Вікторина 2024

Консольна вікторина на C++ з питаннями на різні теми.

## 📁 Файли проекту

- `вікторина.cpp` — основний файл програми українською мовою
- `запуск.bat` — скрипт для компіляції та запуску
- `запуск_вікно.bat` — запуск в окремому вікні
- `Makefile.ua` — файл для автоматичної компіляції

## 🚀 Компіляція та запуск

### Спосіб 1: Запуск через bat-файл (найпростіший)

Просто двічі клікніть на файл `запуск.bat` для компіляції та запуску.

Для запуску в окремому вікні — клікніть на `запуск_вікно.bat`.

### Спосіб 2: Використання Makefile

```bash
# Компіляція
make -f Makefile.ua

# Запуск
make -f Makefile.ua run

# Запуск в окремому вікні
make -f Makefile.ua run-window

# Очищення
make -f Makefile.ua clean
```

### Спосіб 3: Ручна компіляція з g++

```bash
# Компіляція
g++ -std=c++11 вікторина.cpp -o вікторина.exe

# Запуск
вікторина.exe
```

### Спосіб 4: Використання Visual Studio

1. Відкрийте Visual Studio
2. Створіть новий проект "Console App"
3. Скопіюйте вміст `вікторина.cpp` у ваш файл
4. Натисніть F5 для запуску

## 📝 Питання вікторини

1. Хто був одним із найвідоміших художників Голландії у 1600-ті роки?
2. Що з перерахованого не є психічним розладом?
3. Що містить найбільше білка на 100 грам?
4. Найдорожча з коли-небудь проданих картин у світі?
5. Яка наука досліджує закономірності підготовки, вчинення та розкриття злочину?
6. Для визначення чого використовують шкалу Апгар?
7. Скільки кісток складає стопа людини?
8. Який кут нахилу осі обертання Землі?
9. Хто автор картини "Не чекали"?
10. Який острів у Японії є найбільшим?

## 🏆 Система оцінки

- 100% — Ідеально! Ви справжній ерудит!
- 80-99% — Чудовий результат! Так тримати!
- 60-79% — Хороший результат! Є куди рости!
- 40-59% — Непогано, але варто повчитися!
- 0-39% — Не здавайтеся! Спробуйте ще раз!

## 📋 Вимоги

- Компілятор C++ з підтримкою C++11 (g++, clang++, MSVC)
- Windows (для коректного відображення UTF-8)

## 🔧 Налаштування кодування

Програма автоматично встановлює кодування UTF-8 для коректного відображення українських символів.

## 📝 Додавання нових питань

Для додавання нових питань відредагуйте функцію `завантажитиПитання()` у `вікторина.cpp`:

```cpp
{
    "Ваше питання?",
    {"Варіант 1", "Варіант 2", "Варіант 3", "Варіант 4"},
    0 // індекс правильної відповіді (0-3)
},
```
