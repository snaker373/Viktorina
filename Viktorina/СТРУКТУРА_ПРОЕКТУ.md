## Опис основних компонентів

### вікторина.cpp

Основний файл програми, що містить:

#### Переліки (enum)
- `Color` — кольори для консолі

#### Структури
- `Питання` — структура для зберігання питання та варіантів відповідей

#### Функції
- `встановитиКолір()` — встановлення кольору тексту
- `скинутиКолір()` — скид кольору до стандартного
- `встановитиКодування()` — налаштування UTF-8
- `очиститиЕкран()` — очищення консолі
- `встановитиЗаголовокВікна()` — заголовок вікна
- `завантажитиПитання()` — повертає вектор питань
- `показатиЗаголовок()` — відображення заголовка
- `показатиПрогресБар()` — відображення прогресу
- `показатиПитання()` — відображення питання
- `показатиПравильнаВідповідь()` — показ правильної відповіді
- `показатиРезультат()` — відображення результату
- `чекатиНатискання()` — очікування натискання Enter
- `показатиМеню()` — головне меню
- `показатиІнформацію()` — інформація про програму
- `запуститиВікторину()` — основна логіка гри
- `main()` — точка входу програми

### запуск.bat

Batch-файл для Windows, що:
1. Встановлює кодування UTF-8
2. Компілює програму
3. Запускає виконуваний файл

### запуск_вікно.bat

Batch-файл для запуску в окремому вікні консолі.

### Makefile.ua

Файл для утиліти make з ціллю:
- `all` — компіляція
- `run` — запуск
- `run-window` — запуск в окремому вікні
- `clean` — видалення виконуваного файлу

## Залежності

### Обов'язкові:
- Компілятор C++ з підтримкою C++11
- Windows API (для роботи з консоллю)

### Рекомендовані:
- g++ (MinGW)
- Visual Studio

## Компіляція

### Через g++:
```bash
g++ -std=c++11 вікторина.cpp -o вікторина.exe
```

### Через make:
```bash
make -f Makefile.ua
```

### Через Visual Studio:
1. Створити проект Console App
2. Додати файл `вікторина.cpp`
3. Натиснути F5

## Запуск

### Прямий запуск:
```bash
вікторина.exe
```

### Через bat-файл:
Двічі клікнути на `запуск.bat`

### В окремому вікні:
Двічі клікнути на `запуск_вікно.bat`

## Розширення

### Додавання нових питань:

Редагувати функцію `завантажитиПитання()`:

```cpp
{
    "Нове питання?",
    {"Варіант 1", "Варіант 2", "Варіант 3", "Варіант 4"},
    0 // індекс правильної відповіді
},
```

### Додавання нових кольорів:

Редагувати enum `Color`:

```cpp
enum Color {
    // ... існуючі кольори
    НОВИЙ_КОЛІР = 16
};
```
