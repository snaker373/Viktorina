## Ключові рішення

### Вибір C++

**Причини:**
- Швидкодія виконання
- Низький рівень абстракції
- Широка підтримка компіляторів
- Можливість оптимізації

### Вибір Windows API

**Причини:**
- Нативна підтримка кольорів
- Робота з кодуванням
- Широке поширення

### Вибір UTF-8

**Причини:**
- Підтримка українських символів
- Стандарт кодування
- Сумісність з різними системами

## Оптимізація

### Використані техніки:

1. **const correctness** — використання const там, де можливо
2. **pass by reference** — передача об'єктів за посиланням
3. **enum class** — типобезпечні переліки

### Майбутні оптимізації:

- Кешування питань
