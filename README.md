# 🎯 Викторина 2024

Консольная викторина на C++ с вопросами на различные темы.

## 📁 Файлы проекта

- `quiz.cpp` — базовая версия викторины
- `quiz_color.cpp` — версия с цветным выводом и меню
- `Makefile` — файл для автоматической компиляции

## 🚀 Компиляция и запуск

### Способ 1: Использование Makefile (рекомендуется)

```bash
# Компиляция
make

# Запуск
make run

# Очистка
make clean
```

### Способ 2: Ручная компиляция с g++

```bash
# Базовая версия
g++ -std=c++11 quiz.cpp -o quiz.exe

# Цветная версия
g++ -std=c++11 quiz_color.cpp -o quiz_color.exe

# Запуск
quiz.exe
# или
quiz_color.exe
```

### Способ 3: Использование Visual Studio

1. Откройте Visual Studio
2. Создайте новый проект "Console App"
3. Скопируйте содержимое `quiz.cpp` или `quiz_color.cpp` в ваш файл
4. Нажмите F5 для запуска

## 📝 Вопросы викторины

1. Хто був одним із найвідоміших художників Голландії у 1600-ті роки?
2. Що з перерахованого не психічний розлад?
3. Що містить найбільше білка на 100 грам?
4. Найдорожча з колись проданих картин у світі?
5. Яка наука досліджує закономірності приготування, вчинення та розкриття злочину?
6. Для визначення чого використовують шкалу Апгар?
7. Скільки кісток складається стопа людини?
8. Какой угол наклона оси вращения Земли?
9. Кто автор картины "Не ждали"?
10. Какой остров в Японии является самым большим?

## 🏆 Система оценки

- 100% — Идеально! Вы настоящий эрудит!
- 80-99% — Отличный результат! Так держать!
- 60-79% — Хороший результат! Есть куда расти!
- 40-59% — Неплохо, но стоит поучиться!
- 0-39% — Не сдавайтесь! Попробуйте еще раз!

## 📋 Требования

- Компилятор C++ с поддержкой C++11 (g++, clang++, MSVC)
- Windows (для корректного отображения UTF-8)

## 🔧 Настройка кодировки

Программа автоматически устанавливает кодировку UTF-8 для корректного отображения украинских и русских символов.

## 📝 Добавление новых вопросов

Для добавления новых вопросов отредактируйте функцию `loadQuestions()` в `quiz_color.cpp` или вектор `questions` в `quiz.cpp`:

```cpp
{
    "Ваш вопрос?",
    {"Вариант 1", "Вариант 2", "Вариант 3", "Вариант 4"},
    0 // индекс правильного ответа (0-3)
},
```
